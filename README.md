# Md. Shahjalal Ahmed — Portfolio

Premium personal portfolio focused on Meta Ads, GTM, GA4 and conversion tracking.

## Stack
- Next.js 16 App Router
- React 19
- TypeScript
- Vercel-ready

## Admin
The planned admin route is `/admin`.

Set these Vercel environment variables before using the production CMS:
- `ADMIN_PASSWORD`
- `GITHUB_TOKEN`
- `GITHUB_REPOSITORY=tomahmed420/my-protfolio-website-`
- `GITHUB_BRANCH=main`
- `NEXT_PUBLIC_SITE_URL`

The admin currently stores content in `data/content.json` by committing changes to the repository. Keep the GitHub token server-side only and give it the minimum repository permissions needed.
