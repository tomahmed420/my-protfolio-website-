# Portfolio Redesign PRD

## Goal
Build a premium personal portfolio for Md. Shahjalal Ahmed that positions him as a specialist and converts qualified visitors into high-ticket client inquiries.

## Core positioning
**Meta Ads & Conversion Tracking Specialist**

Core services:
- Meta Ads
- Google Tag Manager (GTM)
- Google Analytics 4 (GA4)
- Conversion Tracking

The ICP is intentionally not locked yet. The site must be specific about the capability while remaining flexible enough to refine the niche after stronger evidence is collected.

## Brand principles
- Minimal
- Clean
- Specific
- Premium
- Strong whitespace
- Confident, analytical, outcome-focused
- No generic agency/freelancer language
- No fake proof or unverified metrics
- No excessive visual decoration

## Homepage flow
1. Hero — positioning, value proposition, primary/secondary CTA
2. Trust / expertise
3. About / authority
4. Services
5. Featured Meta Ads case study
6. More case studies
7. Testimonials
8. Projects with Client Work / Vibe Code switch
9. Final CTA
10. Footer

## Portfolio priority
Meta Ads case studies and verified performance/tracking proof are the primary portfolio evidence.

Vibe Code is secondary and should never dominate the core service positioning.

## Admin
Route: /admin

Admin must eventually allow editing of:
- Hero/site copy
- Services
- About/principles
- Proof metrics
- Featured case study
- Case studies
- Testimonials
- Client Work projects
- Vibe Code projects
- Contact details
- Social links
- Media

## Technical direction
- Next.js App Router
- TypeScript
- Responsive desktop/mobile
- Vercel deployment
- Server-side admin authentication
- Persistent content storage
- Keep secrets server-side only

## Execution rule
Work in implementation order, not endless redesign loops. Once a visual direction is approved, preserve it unless the owner explicitly asks to revisit it.

## Proof rule
Never publish invented results, client names, testimonials, revenue numbers, ROAS, or experience claims as real proof. Use clearly marked placeholders until verified evidence is supplied.
